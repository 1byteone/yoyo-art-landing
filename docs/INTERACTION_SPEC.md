# 交互规范

## 全局规则

- 交互入口使用原生 a、button、input、select 与 dialog 语义；点击目标具有可访问名称。
- 当前状态用 aria-pressed、aria-selected、aria-expanded 表达；结果数量由可见数据推导。
- 键盘 Tab 可进入原生控件；作品预览使用原生 dialog，可由 Escape 或关闭按钮退出。
- 章节链接全部指向当前页面的真实锚点，不伪装成外部业务提交或未实现路由。
- 系统 prefers-reduced-motion 开启后，所有主要内容立即可见；滚动视差/揭示过渡关闭；海报自动保持静止且播放按钮禁用。
- 预览、搜索、筛选和空状态均提供清晰反馈。缺失素材详情显示缺失状态，不显示相似图片。

## 资产探索器分页约定

每页最多 12 项。范围为 16 张主图、49 项辅助资产和 65 项合并资产；搜索在 ID、名称、路径/来源、用途和分类中匹配。切换范围、类别、状态或关键词会把页码重置到第一页，避免空白页。

## 滚动行为

Hero 三条图片轨道使用线性无缝循环，桌面速度为左/右/左约 36/32.3/36 CSS px/s；周期依据每轨真实循环宽度和 -8° 倾角水平投影计算，尺寸变化时由 ResizeObserver 更新。提供全轨暂停/继续控件；悬停不影响页面滚动。启用 prefers-reduced-motion 后轨道自动静止，控件禁用并说明系统状态。

页面视差事件通过 requestAnimationFrame 合并为一次更新，幅度由元素 data-scroll-parallax 配置。减少动态偏好变化时清理事件、取消待执行帧并删除位移状态。IntersectionObserver 只在进入视口后揭示一次。
