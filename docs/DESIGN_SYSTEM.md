# 设计系统

当前设计目标：高识别度、编辑式、可操作的 YOYO 数字艺术实验场。桌面变体采用非对称构图；手机端重排内容而不是整体缩小。

## 色彩令牌

| 令牌     | 值                | 职责                               |
| -------- | ----------------- | ---------------------------------- |
| YOYO 紫  | #7139E8           | 品牌识别、章节强调、选中状态       |
| 深紫     | #5120BA           | 深色背景上的紫色层级与部分文字强调 |
| 荧光绿   | #B8F32F           | 操作焦点与有限面积的高亮           |
| 墨色     | #171717           | 主文字、描边、强对比按钮           |
| 暖纸白   | #F7F6F0 / #F7F6F2 | 页面与 Hero 的主背景               |
| 素材纸白 | #F6F6F6           | 与联系表裁图的固定背景色对齐       |
| 软灰     | #EEEEE7           | 模块面板与构图画布                 |
| 次级文字 | #666963           | 辅助说明、元信息                   |

彩色控制点和对象使用真实色样；文字按钮只用于明确动作。避免大面积渐变、玻璃质感与无意义粒子。

## 字体与层级

| 用途          | 当前规则                                         |
| ------------- | ------------------------------------------------ |
| 中文正文/控件 | Arial、PingFang SC、Microsoft YaHei 系统回退栈   |
| 中文标题      | Instrument Serif、Noto Serif SC、宋体系统回退栈  |
| Hero 标题     | 桌面约 40–50px；700px 以下 34px；380px 以下 28px |
| 章节标题      | 桌面约 35–59px；手机端约 37px                    |
| 正文          | 桌面约 12–13px；手机端约 11px；行高约 1.85–1.9   |
| 说明/编号     | 大多 7–10px，作为标注层；需关注可读性差异        |

项目没有打包专用字体文件；标题衬线效果依赖操作系统可用字体。因此不同平台的字形和行宽可能有差异。若交付要求跨平台字体一致，应提供有授权的字体文件并纳入本地加载。

## 布局与空间

- 页面内容最大宽度约 1240px，左右留白由 clamp(22px, 5vw, 84px) 控制。
- Hero 桌面采用文案/画布双栏；900px 以下转为纵向叠放。
- 作品网格桌面为 12 栏，通过 3/4/6 栏跨度形成不对称节奏；700px 以下改为 2 栏并保留少量通栏图。
- 模块画布、应用预览与详情弹窗使用明确的固定/比例约束，避免内容动态撑开控件。
- 通用细线透明度约 14–30%；硬边、网格和边界线承担空间组织，不把每个区域封装成圆角卡片。

## 层级

页面 z-index 令牌定义 background、atmosphere、midground、gallery、foreground、decoration、content、controls 八级。Hero 的三类前景图按源图宽高比显示；构图实验只切换已有素材图层，不声称将完整插画拆开。

## 动效

- 进入揭示：IntersectionObserver，阈值 0.08，根边距底部 -32px；每个节点只揭示一次。
- 滚动视差：requestAnimationFrame 合并滚动事件，依据元素中心和视口中心计算有限幅度的 translate；当前 Hero 层强度为 16/26/34px，构图主体为 20px。
- 海报运动：默认静止，由用户显式播放/暂停。
- prefers-reduced-motion：不运行滚动位移、揭示过渡和海报动画，并直接显示全部内容。
