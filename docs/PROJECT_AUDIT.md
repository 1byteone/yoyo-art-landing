# 项目审计

审计日期：2026-11-23。审计对象：当前 YOYO Art Landing 工作区；本文件描述品牌实验场版本，不描述历史 Oil UI 仿制版本。

## 项目概况

| 项           | 现状                                                       |
| ------------ | ---------------------------------------------------------- |
| 类型         | React 单页品牌展示与交互原型                               |
| 技术         | React、TypeScript、Vite、Lucide、Playwright                |
| 路由         | 无客户端路由；章节使用页面内锚点                           |
| 数据         | 本地 TypeScript 内容与素材模型；无后端 API、数据库或持久化 |
| 入口         | src/main.tsx → src/App.tsx                                 |
| 构建         | TypeScript project build + Vite build                      |
| 视觉测试服务 | 127.0.0.1:4179，Playwright 配置启动或复用 Vite             |

## 页面结构

页面从品牌 Hero 开始，依次叙述视觉基因、空间构图、行业应用和实验目录；随后是交互画廊、资产探索器、动态海报、工作流场景、模块实验台、收尾 CTA 与页脚。六项实验是页面章节内的可操作演示，不是六个独立部署产品。

## 本轮发现与处理

1. 作品画廊虽声明了列数和跨栏规则，却缺少 display:grid，导致卡片在所有视口中垂直单列。现已补齐网格声明，并新增断言检查桌面 12 栏、手机 2 栏及真实网格显示。
2. ScrollReveal 组件此前未挂载，页面无滚动揭示逻辑。现已挂载到 App，并为 Hero/构图图层接入 requestAnimationFrame 节流的滚动位移；减少动态偏好会恢复静态状态。
3. 辅助资产数据包含已删除样式文件路径。已将路径改到现存模块，并让资产生成器在 Integrated 条目的任一路径缺失时失败。
4. docs/reconstruction 下的实现审计与差异文件仍描述上一轮 Oil UI 几何克隆。已在档案索引中标记为历史资料，当前状态以根 docs 文档为准。

## 保留的工程风险

- 16 张插画的像素尺寸有限，Hero 大图上采样会显露柔化；CSS 无法恢复原始细节。
- 49 项辅助资产里有 22 项缺少独立文件。当前资产查看器明确展示缺失状态，不以近似图替代。
- 页面 CSS 按 tokens、global、gallery、landing、yoyo-experience 顺序加载，最后一份样式覆盖部分旧基础选择器；未来修改共享选择器时需跑视觉回归。样式归并属于后续维护项，本轮未进行无关重构。
- 交互是前端演示，没有账号、远端内容、提交表单、持久化或真实业务流程。

## 说明

当前任务聚焦前端体验，与后端无关；工作区未找到 RTK.md。项目没有依赖 Spring 层、数据库或 API 服务。
