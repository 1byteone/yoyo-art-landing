## 明确限制

- 主图源为联系表裁切，384 × 256；没有独立的高分辨率源文件。
- 22 项辅助素材缺失；显示在目录中并保持 Missing 状态。
- 互动为浏览器端演示状态，没有 API、用户数据保存、账号或真实交易/联系提交。
- 字体栈依赖系统回退；要稳定跨平台效果需提供合法可嵌入字体。
- 不声称与 Oil UI 页面像素级相同；页面采用其叙事方法，视觉和内容独立于参考品牌。
