> 本文件记录较早一轮 Oil UI 几何仿制状态，不描述当前 YOYO 品牌实验场。请以 docs/PROJECT_AUDIT.md、docs/VISUAL_GAP_REPORT.md 和 docs/VISUAL_QA_REPORT.md 为当前基准。

审计日期：2026-11-23。对象为 YOYO Art Landing 当前实现；重构前截图保存在 `artifacts/before/`，目标站证据保存在 `artifacts/reference/`。

## 结论

页面已由“左文案 + 单图轮播 + 自造作品网格”重构为参考站的 6 段长页节奏：56px 导航、居中 Hero 与倾斜多行画面墙、Why/01 编辑式视觉证据、02 页面一致性对比与三行业切换、深色宣言、20 项风格档案、限宽深色转化板及轻量页脚。1440×900 下的主要区块坐标与高度已通过 Playwright 对齐记录的原站 DOM 测量。本轮修复了前景 2/3 的定位/拉伸故障，并将画面墙卡片几何、每轨重复数和滚动速度按原站 1440×900 实测校准；这仍不是像素级原站复刻。

这不是素材意义上的逐像素原站复制：用户提供的 16 张图是单张 1536×1024 contact sheet 的 384×256 裁切衍生图，并非 16 张独立高分辨率网页截图。W17–W20 使用明确的素材待补占位，不复制其他图片。原站其他视口未成功采集，不能声称移动端与原站像素一致。

## 剩余差异

- Hero 的 16 张可用图来自等距积木场景裁切，现用于 3 条各 7 张的轨道，存在 5 个跨轨复用位置；原站使用 Oil UI 网页预览。卡片几何和水平速度已校准，画面内容不可等同。
- 49 项辅助资产清单仍单独维护：22 项缺失，16 项为可用图像条目，11 项为 CSS/DOM 实现条目。CSS/DOM 条目不是独立原始位图；不能把这些实现等同于已拿到全部辅助图像素材。
- 原站 1920×1080、1280×800、768×1024、390×844、375×812 的重采集曾超时/断连；移动端结构是为当前项目单独适配。
- 行业区域和案例详情使用本地可用场景及文案适配，未声称是原站完整项目源码或案例网页。
- 三版前景切换按钮按 1→2→3→1 循环。前景 2/3 曾因 static 正常流和固定高度拉伸覆盖上层，现改为底部 absolute 且恢复原始比例；三张素材都不等同于原站植物前景。
- 原站与 round-13 同视口像素分区数据、动态测量和剩余差距见 `PIXEL_LEVEL_DIFFERENCE_ANALYSIS.md`。
