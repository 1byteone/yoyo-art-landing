# 历史阶段原站与本地像素差异分析

归档说明：本文测量的是此前的 Oil UI 几何仿制版本，不描述当前 YOYO 品牌实验场。当前项目刻意采用 YOYO 视觉表达，因此不能以此页的像素差分作为当前质量结论。当前差异见 docs/VISUAL_GAP_REPORT.md。

审计日期：2026-11-23。参考对象：[Oil UI Art Landing](https://ui.oiloil.org/art-landing/)；本地对象：历史 YOYO 实现。本文合并记录当时的前景图故障诊断、原站实时滚动测量、Playwright 证据和同尺寸像素差分。

## 结论摘要

本轮确认第 2、3 版前景图的主要故障不是素材尺寸本身，而是它们没有绝对定位：图片以普通文档流方式从前景层顶部开始绘制；HTML 的 `height="736"` 又在 CSS 缩窄宽度时仍维持固定高度，令 2135×736 的透明 PNG 被拉伸并遮住展示墙。现在两张图在底部绝对定位、按源宽高比缩放，1440×900 下的图像盒已从旧版 `y=56、1440×736、静态定位` 改为 `y=467.59、1440×496.41、绝对定位`，CTA 区不再被图片盒覆盖。

展示墙也由本地先前的 6/5/5 张分轨、不同周期常量调整为与原站一致的 3 轨、每轨 7 张后重复、左/右/左方向；桌面卡片 CSS 尺寸、比例、间距、倾角和轨道速度均以原站 1440×900 实时 DOM 数据校准。剩余的最大差距仍是画面内容：本地是 YOYO 积木场景裁切图和平台型前景，原站是 Oil UI 网页预览和植物/花园前景。素材不同意味着最终像素不可能仅凭 CSS 调整达到原站像素级一致。

这次一并收紧了验收条件。旧测试只要求图片盒与 Hero 矩形相交，即使图片仍然被画在顶部、严重变形也会通过；新测试检查图片盒在 CTA 下方、位于 Hero 下部、宽高比等于源素材比例，并在用户提交的两个视口尺寸下保存截图。三张前景切换、图像解码和切换提示仍由交互测试覆盖。

**仍然存在的素材差异：**前景 2/3 是不透明度正常的积木岛屿/产品平台图，原站前景是植物、花园和摄影质感。现在修正的是尺寸、定位和叠层关系，不会把几何积木变成原站植物；原站的前景素材和本地源图的边缘抠图也不相同。

## 3. 图片滚动：原站实测与本地校准

### 原站 1440×900 实测

原站在浏览器中有 3 条独立的 `.al-marquee-track`。每条轨道包含 14 个卡片 DOM 节点，即 7 张不同预览加一组重复内容用于循环。父级旋转为 -8°，每张卡片 CSS 盒为 256×160px，卡片间距 14px；相邻卡片布局步长为 270px。经过父级变换后，卡片可见包围盒为 275.78×194.07px，相邻卡片在屏幕上的 x/y 位移为 +267.37/-37.58px。

| 原站轨道 | CSS 动画方向  | 周期 |       连续取样位移 | 取样估算水平速度 |
| -------- | ------------- | ---: | -----------------: | ---------------: |
| 上轨     | normal，向左  |  52s | 约 -43.63px / 1.2s |     约 36.36px/s |
| 中轨     | reverse，向右 |  58s | 约 +39.11px / 1.2s |     约 32.60px/s |
| 下轨     | normal，向左  |  52s | 约 -43.63px / 1.2s |     约 36.36px/s |

这是一段实时浏览器的短间隔取样，不是逐帧录屏；方向、周期和每卡坐标由 computed style / DOM 检查，速度由约 1.2 秒的 `getBoundingClientRect().x` 差值估算。不同步的独立采样存在少量计时误差。

### 本地 round-13 校准

| 轨道 | 独立卡片 + 循环副本 | 方向 |                 CSS 循环位移 | 水平速度 | 动态周期 |
| ---- | ------------------: | ---- | ---------------------------: | -------: | -------: |
| 上轨 |               7 + 7 | 向左 | 1871.61px（含 -8° 水平投影） | 36.0px/s |  51.989s |
| 中轨 |               7 + 7 | 向右 | 1871.61px（含 -8° 水平投影） | 32.3px/s |  57.945s |
| 下轨 |               7 + 7 | 向左 | 1871.61px（含 -8° 水平投影） | 36.0px/s |  51.989s |

周期由当前媒体断点下每轨真实宽度、轨道间距和墙面旋转的水平投影动态计算，并由 `ResizeObserver` / `resize` 更新；不再让屏幕变宽时动画只变“看起来更慢”。CSS 卡片盒与原站测量值对齐为 256×160px、14px 间距和 -8° 倾角。以同一浏览器几何反算，原站周期预计对应约 36.0/32.3/36.0px/s，与本地设定基本一致。

**当前仍与原站不同：**本地 16 张可用 YOYO 图需要分配到三条各 7 张的轨道，因此有 5 个跨轨复用位置；图片内容、序列和页面缩略图标签不等同于原站 20 张 Oil UI 项目预览。相同速度和循环长度只能对齐运动学，不代表图像序列或前后层叠内容相同。

## 4. 首屏像素差分

比较方式：参考图 `live-1440.png` 和本地 round-13 PNG 均为 1440×900。RGB MAE 为所有颜色通道绝对差的平均值，范围 0–255；“差异像素 >16”按单个像素三个通道绝对差的平均值大于 16 统计。差异热图将该像素平均差乘 3 写入红色通道。分区按固定 y 范围切分，不代表 DOM 边界。

| 本地状态   |      RGB MAE | 像素差 >16 | 像素差 >32 | 像素差 >64 |
| ---------- | -----------: | ---------: | ---------: | ---------: |
| 默认前景 1 | 45.857 / 255 |     51.81% |     43.36% |     29.76% |
| 前景 2     | 43.510 / 255 |     50.49% |     41.58% |     28.59% |
| 前景 3     | 42.497 / 255 |     49.70% |     40.43% |     27.89% |

| 分区（1440×900） |  y 范围 | 默认前景 1 MAE / >16 | 前景 2 MAE / >16 | 前景 3 MAE / >16 |
| ---------------- | ------: | -------------------: | ---------------: | ---------------: |
| Header           |    0–56 |       13.731 / 5.85% |   13.731 / 5.85% |   13.731 / 5.85% |
| 标题、说明与 CTA |  56–330 |       11.577 / 7.77% |   11.577 / 7.77% |   11.577 / 7.77% |
| 展示墙上段       | 330–560 |      52.586 / 64.71% |  52.556 / 64.70% |  52.557 / 64.70% |
| 展示墙与前景下段 | 560–900 |      74.223 / 86.14% |  68.030 / 82.67% |  65.348 / 80.56% |

全页 1440×6900 的默认前景图与原站截图比较：RGB MAE **38.233 / 255**、差异像素 >16 **34.27%**。分区结果：Header + Hero 51.904 / 55.28%，Why/Craft 61.152 / 46.51%，行业区 20.137 / 18.88%，宣言区 17.667 / 28.28%，案例档案 42.755 / 36.95%，转化区与页脚 10.462 / 4.87%（每项依次为 MAE / >16）。局部页面差异仍比全页平均值大；较低的转化区差异不能抵消首屏与案例图像不匹配。

不同前景状态 MAE 有差异，不应直接解读为“前景 3 比原站更像”。前景状态会改变大面积像素颜色，而参考图里又有植物、淡色环境和网页缩略图；数字反映颜色差，不识别物体语义，也不判断设计质量。动画采样相位、字体光栅化和图像加载状态同样会改变像素统计。原站连续动画相位没有与本地 screenshot 同步，因此这些数值只作差异定位，不作为单独验收门槛。

## 6. 剩余差距与优先级

1. **P0：补正确图像源。** 若验收目标是原站截图级复刻，需要 Oil UI 的 21 组滚动卡片内容、原始项目预览、植物前景和品牌图形。现有 contact sheet 裁切和 YOYO 积木前景不能替代它们。未拿到素材前应把这项列为阻塞的视觉依赖，而不是宣称像素级完成。
2. **P0：统一页面身份与文字。** 目前页面仍是 YOYO 产品表达，不是 Oil UI 页面。需要明确保留 YOYO 品牌还是复刻 Oil UI 品牌；只要标题、标志和按钮文案不同，像素差和语义差就会持续存在。
3. **P1：持有同视口原站视觉基准。** 本地已在用户截图尺寸做修复检查，但原站目前只有 1440×900 的成功截图；其他尺寸的匹配结论只能称为本地适配。
4. **P1：素材接入后重做像素回归。** 对齐同滚动位置、同动画相位并确保原站素材完整加载，生成 overlay / heatmap；逐张检查 `object-fit`、`object-position`、卡片裁切、标签和阴影。
5. **P2：核查更细动效。** 本轮对齐了滚动方向、线性运动、速度、周期与 7+7 循环。原站响应式下的断点变化、hover 状态、暂停控制和低动态偏好仍需独立采集，不能从本地功能推断。

## 7. 验收结论

- **前景功能：** 已修复第 2/3 版普通流定位和宽高比拉伸缺陷；切换按钮、图片解码、CTA 间隔和 1338×1153 / 1315×1173 截图回归通过。
- **图片滚动：** 三条轨道方向、独立卡片数、卡片盒、倾角、间距和速度均由原站 1440×900 证据校准；本地仍使用不同图片内容。
- **像素级复刻：** 未完成。首屏 MAE 仍约 42–46 / 255，最大残差集中在主图、前景和页面品牌内容；该值也受动画相位影响。
- **自动化：** `npm run verify` 通过 6 项 Playwright 测试、TypeScript、ESLint 和 Prettier 检查；`npm run build` 通过。

实现文件：`src/components/HeroGallery.tsx`、`src/styles/spatial-scene.css`；交互与截图回归：`tests/interactions.spec.ts`、`tests/visual.spec.ts`。
