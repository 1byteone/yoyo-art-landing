## 素材映射原则

1. `public/assets/gallery/01...16` 是用户 contact sheet 的 384×256 裁切版本，所有原文件不重绘。
2. W01–W16 到这 16 张裁切素材一对一映射；行业预览和 Hero 可复用，但档案不重复冒充独立案例素材。
3. W17–W20 保留真实案例名称与分类，但无图显示“主视觉素材待补”，预览也不载入其他案例图片。
4. 三种用户提供的 RGBA 前景图从 `/assets/foreground/` 切换；前景 2/3 保持 2135×736 源比例并锚定 Hero 底部，前景不遮住标题与 CTA。它们均为积木/平台题材，不是原站植物素材。
5. 49 项辅助资产清单按 integrated/missing 单独管理；纯 CSS 形状不能替代缺失的原始位图状态。
