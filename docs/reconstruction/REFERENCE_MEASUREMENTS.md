## Hero 展示墙与滚动实测

原站在 2026-11-23 的实时 1440×900 浏览器采样中有 3 条 `.al-marquee-track`，动画函数为 linear。每条轨道有 14 个卡片节点，即 7 张独立预览和一组重复图像；track 的 `offsetWidth` 为 3766px，轨道 gap 为 14px。父级 `.al-marquee-tilt` 的 computed transform 是 `rotate(-8deg)`。

| 轨道 | CSS `animation-direction` | 周期 |       连续取样位移 | 取样水平速度 |
| ---- | ------------------------- | ---: | -----------------: | -----------: |
| 上   | normal                    |  52s | 约 -43.63px / 1.2s | 约 36.36px/s |
| 中   | reverse                   |  58s | 约 +39.11px / 1.2s | 约 32.60px/s |
| 下   | normal                    |  52s | 约 -43.63px / 1.2s | 约 36.36px/s |

首张卡片 `offsetWidth × offsetHeight` 为 256×160px，卡片间距 14px，因此布局步长为 270px；第二张卡片的 `offsetLeft` 比第一张增加 270px。父级旋转后，同一对卡片在 `getBoundingClientRect()` 中为约 275.776×194.071px，x 差 +267.372px、y 差 -37.577px。卡片图片的源尺寸为 1120×700。

位移来自连续两次读取 `getBoundingClientRect().x` 的短间隔样本，适合估算而非高精度时间基准；周期与方向读取 computed style，卡片尺寸和重复数量读取 DOM。源站帧相位会影响短样本速度，不将估算到的小数当作绝对常数。

## 首屏视觉证据

`live-1440.png` 显示：浅暖灰首屏、顶栏单行、居中衬线标题及说明、两枚居中 CTA；下半屏为 4–5 列不等宽网页画面组成的倾斜墙，页面边缘有植物/环境画面，植物与展示墙存在前后层叠。墙面不是单张轮播，也不是均匀平铺缩略图。

## 本地实现校准结果

在同一 1440×900 视口，本地 Playwright DOM 测得 Header x=36/y=0/1368×56，Hero y=56/h=844；后续 Why/01、02/行业、宣言、案例档案分别从 y=900、1818、2788、3273 开始；限宽 CTA 为 x=100/y=6252/1240×534，Footer 从 y=6786 开始，整页高 6900px。round-13 截图见 `artifacts/after/round-13/desktop-1440.png` 和 `desktop-fullpage.png`。

本地滚动墙 round-13 已按原站的 256×160px 卡片、14px gap、-8° 倾角、7 张独立内容循环和左右方向设置。每轨循环 CSS 位移为 1890px；计入 -8° 水平投影后为 1871.607px。目标水平速度 36/32.3/36px/s，动态周期实测为 51.989/57.945/51.989s。前景 2/3 在 1440×900 的图像盒为 x=0、y=467.594、1440×496.406，定位为 absolute，渲染比例 2.90085；PNG 源比例约 2.90082。

本地响应式覆盖 1920×1080、1280×800、768×1024、390×844、375×812、320×740；另外按本轮用户截图尺寸复验前景 2/3：1338×1153 与 1315×1173。以上仅表示本地适配与前景不遮挡标题/CTA，不是原站实测断点。

像素差分与逐区残差分析见 `PIXEL_LEVEL_DIFFERENCE_ANALYSIS.md`。最新本地首屏/全页截图和三版前景状态均在 `artifacts/after/round-13/`；前景 2/3 同用户截图尺寸的证据也在该目录。
