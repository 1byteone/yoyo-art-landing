# 参考素材提交清单

完整页面复刻的质量首先取决于参考证据和原始素材。**一张首屏截图只能还原一个视口、一个滚动位置和一个交互状态**；它无法提供完整页面、移动端断点、轮播相位、图片原图或透明层关系。

## 必需输入

### A. 页面与浏览器信息

- [ ] 参考页面 URL；如有多个页面，标注主入口与必须复刻的路由。
- [ ] 目标品牌、页面用途、希望复刻到什么范围（单个 Hero / 一页 / 整个站点）。
- [ ] 浏览器、视口 CSS 宽高、设备像素比、缩放比例、登录/地区/语言状态。
- [ ] 说明哪些原站文字、商标和图片拥有复用授权；没有授权的内容须替换为用户自有素材。
- [ ] 指定目标技术栈和项目目录；未指定时让 Agent 先审查现有项目，不覆盖已有实现。

### B. 页面截图

- [ ] 桌面首屏截图：优先 **1440×900 CSS px**，PNG，无浏览器工具栏、无鼠标悬停遮罩。
- [ ] 桌面完整长页截图：在页面顶端捕获完整滚动内容；需能辨认章节边界和页脚。
- [ ] 至少一个平板截图：建议 768×1024。
- [ ] 手机首屏和完整长页：建议 390×844；若有 320px 或 375px 特殊适配也提供。
- [ ] 关键区域特写：导航、Hero、卡片/画廊、表单/弹窗、页脚等小字或微间距区域。
- [ ] 同一截图注明捕获日期、滚动位置、设备像素比和页面状态。

截图应用 PNG 无损格式。不要通过聊天软件压缩后的图片来判断 1–2px 边距或字体抗锯齿。

### C. 原始图片与图层（复刻质量的关键）

- [ ] Logo：SVG 优先；同时提供深色/浅色版本、最小留白和允许的最小尺寸。
- [ ] Hero 主图、轮播图和每一张案例图的**独立原文件**，不要只给拼版/联系表/整页截图。
- [ ] 前景、中景、背景分层文件；需要遮挡的前景提供带 Alpha 通道的透明 PNG/WebP。
- [ ] 纹理、贴图、产品 UI、装饰物、图标和海报单独提供，注明它们在页面里的角色。
- [ ] 尽量提供源文件尺寸；若只提供截图，说明目标渲染尺寸和可接受的裁切范围。
- [ ] 说明每张图的展示策略：`contain` / `cover`、焦点位置（如 `object-position: 50% 35%`）、允许裁切边缘。
- [ ] 透明素材应保留原 Alpha，不要先加白底、棋盘格或阴影；阴影由页面 CSS 控制时不要烘焙进图像。

建议原始位图至少达到最大 CSS 展示尺寸的 2 倍；超宽场景、视差大图按实际最大显示宽度另行提供更高分辨率。高分辨率不是把截图放大，而是提供源导出文件。

### D. 字体、色彩与文案

- [ ] 字体文件（WOFF2 优先）及其 Web embedding 授权；标注标题、正文、数字和替代 fallback。
- [ ] 品牌色、背景色、正文/弱化文字、描边、焦点/选中/禁用状态的 HEX/RGB 值；如无值，注明从截图估算。
- [ ] 原始文案、字号/字重/行高或设计文件；说明哪些文字必须逐字保留。
- [ ] 图标 SVG/源文件；说明 Lucide 等开源图标是否可替代。

### E. 动效与交互

- [ ] 轮播、页面滚动、视差、鼠标悬停、菜单开合、Tab、弹窗等 **5–15 秒录屏**，最好分别提供桌面和手机。
- [ ] 说明触发方式、运动方向、时长/速度、缓动曲线、循环间隔、是否可暂停。
- [ ] 对自动播放提供暂停方式，并说明 `prefers-reduced-motion` 下的预期行为。
- [ ] 每种状态至少一张截图：默认、悬停、选中、打开、错误/空结果、减少动态等。
- [ ] 若素材很多，提供 CSV/JSON 对照表，把截图区域/案例 ID 映射到原图文件名。

## 推荐目录

```text
reference-input/
  README.md                 # 页面 URL、采集条件、授权范围
  screenshots/
    desktop-1440x900.png
    desktop-full-page.png
    tablet-768x1024.png
    mobile-390x844.png
    mobile-full-page.png
  recordings/
    hero-motion.mp4
    interactions.mp4
  assets/
    logo.svg
    hero/
      hero-track-01.webp
      hero-track-02.webp
      foreground.png
      midground.png
  fonts/
  asset-map.csv
```

`asset-map.csv` 至少包含 `asset_id,file,section,layer,native_width,native_height,alpha,fit,position,notes,license`。文件名稳定且唯一，能让 Agent 更新一个数据清单而不用在几十个组件里搜索/替换路径。

## 不能提供的素材怎么办

1. 标记缺失素材和受影响区域，不允许用相似图库图假装是原图。
2. 询问用户是等待授权素材、按现有素材尽力近似，还是用自有/许可素材替换。
3. 若先做近似版，在 README 和差异报告中标明“占位/近似”和具体尺寸或语义差距。
4. 不抓取受登录/访问控制保护的页面，不绕过访问限制；不把未获授权的原站截图/商标提交到公开仓库。
